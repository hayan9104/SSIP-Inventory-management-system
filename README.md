# SSIP Inventory Management System

The **SSIP Inventory Management System** is a web-based application designed to streamline the process of managing inventory within an organization. It offers functionalities for tracking products, managing stock levels, and generating reports, thereby enhancing operational efficiency.

## Features

- **Product Management**: Add, update, and delete product information with ease.  
- **Stock Tracking**: Monitor stock levels in real-time to prevent overstocking or stockouts.  
- **User Authentication**: Secure login system to ensure authorized access to the system.  
- **Reporting**: Generate detailed reports on inventory status and transaction history.  

## Technologies Used

- **Frontend**:  
  - HTML, CSS  
- **Backend**:  
  - Python with Flask framework  
- **Database**:  
  - My SQL
